Project: Piggy Boss

Purpose
- Piggy Boss is a website to manage personal finance in a simple, accessible and fast way.

High-level architecture
- Monorepo with two main pieces:
  - `backend/` — Django + Django REST Framework (Python)
  - `frontend/` — React + Vite (TypeScript/JSX)

How to run (overview)
- Backend: activate the Python venv in `backend/`, install requirements, then run `python3 manage.py runserver`.
- Frontend: install node deps in `frontend/` and run `npm run dev` (Vite).

Important files & entrypoints
- Backend: `backend/manage.py`, `backend/piggyboss/settings.py`, `backend/account/`, `backend/finance/`, `backend/planning/`, `backend/dashboard/`.
- Frontend: `frontend/src/main.jsx`, `frontend/src/app/App.tsx`, `frontend/src/features/`, `frontend/src/shared/`.
